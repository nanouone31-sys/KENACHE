# كناش

دفتر طلبيات وأرباح لبائعي Vonder/FreeVendor، مع Yalidine للتوصيل. التطبيق ملف HTML واحد بلا خادم، والبيانات تُحفظ على جهازك.

## التشغيل

الطريقة الموصى بها:

```bash
node kanach-proxy.js
```

ثم افتح `http://localhost:8787`. الوسيط يخدم التطبيق ويمرّر طلبات Yalidine من IP حاسوبك، فلا مشاكل CORS ولا حاجة لملء «رابط الوسيط». ومن هذا الرابط يمكن تثبيت كناش كتطبيق، ويعمل بلا إنترنت.

ويمكن أيضاً فتح `kanach.html` مباشرة (لكن بلا تثبيت ولا عمل دون إنترنت).

## الملفات

| الملف | الدور |
|---|---|
| `kanach.html` | التطبيق كاملاً |
| `kanach-proxy.js` | وسيط محلي لـ Yalidine ويخدم التطبيق (اختياري: `KANACH_ORIGINS` لحصر المواقع المسموح لها) |
| `sw.js`, `manifest.webmanifest`, `icon.svg` | التثبيت كتطبيق والعمل دون إنترنت |
| `tests/kanach.test.js` | اختبارات في متصفح حقيقي: `node tests/kanach.test.js` (يحتاج Playwright) |

## الحساب

- سعر التطبيق = سعر المنتج × الكمية + عمولة Vonder (6%) + هامش أمان اختياري (0 افتراضياً، ويبقى لك) + الإضافي + فائدتي
- سعر الزبون = سعر التطبيق + فائدة البائع
- التوصيل: الزبون يدفع سعر توصيل **FreeVendor** فوق سعر الزبون. Yalidine يقتطع سعر توصيله هو، و**0.75%** من المبلغ المحصَّل عند كل تسليم ناجح.
  - تكلفة التوصيل عليك = (Yalidine − FreeVendor) + 0.75% × (سعر الزبون + توصيل FreeVendor)
  - الفائدة الصافية = فائدتي + هامش الأمان − تكلفة التوصيل
  - مثال (أدرار، منزل، سعر زبون 14 600): 1400 − 1000 + 117 = 517 دج عليك، فتصبح فائدة 1048 صافياً 531.
- الجدولان مأخوذان من «Tarifs de livraison» لـ FreeVendor ولـ Yalidine (28/10/2026). FreeVendor لا يوصّل إلى برج باجي مختار وعين قزام وجانت.
- القيمة المتوقعة = نسبة التسليم × الفائدة − نسبة المرتجع × Taxe retour. نسبة التسليم من سجل الولاية إن كانت فيها 5 طلبيات محسومة على الأقل، وإلا النسبة العامة، وإلا القيمة المفترضة.
- يتحقّق التطبيق من النموذج تلقائياً بمقارنته بـ Net الحقيقي للطلبيات المؤكدة.
