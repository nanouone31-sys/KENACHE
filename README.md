# كناش

دفتر طلبيات وأرباح لبائعي Vonder/FreeVendor، مع Yalidine للتوصيل. التطبيق ملف HTML واحد بلا خادم، والبيانات تُحفظ على جهازك.

## الواجهة

خمسة تبويبات، بترتيب العمل اليومي:

- **الرئيسية**: صافي الفائدة، ثم **مسار الطلبيات** بخطواته الخمس: تأكيد مع الزبون، رفع إلى Yalidine، طباعة الملصقات، في الطريق، التسديد. لكل خطوة عددها، وتُفتح بنقرة واحدة. تحتها التنبيهات: زبائن للاتصال، مبالغ مختلفة، طرود متأخرة، منتجات بلا سعر شراء.
- **الطلبيات**: كل الحركات، مع البحث والفلاتر.
- **المنتجات**: منتجاتي (سعر الشراء والبيع)، والمبيعات لكل منتج، وحاسبة السعر.
- **الأرباح**: الملخص، والتسديد، والولايات، والعملاء.
- **الإعدادات**: الربط (الهاتف والحاسوب، Yalidine، FreeVendor، تأكيد الطلبيات)، والحساب والطباعة، والبيانات.

زر التحديث في الأعلى يحدّث حالات Yalidine والمزامنة معاً، ونقطته الملوّنة تلخّص حالتهما.

## كناش السحابي: الهاتف والحاسوب بنفس البيانات

Worker واحد على Cloudflare (مجاني) يستضيف كناش، ويزامن البيانات، ويستقبل طلبيات FreeVendor من أي جهاز، ويرسل إشعارات التسليم إلى الهاتف حتى وكناش مغلق. وكل تحديث يُدمج في `main` يُنشر وحده. خطوات النشر في **[DEPLOY.md](DEPLOY.md)**.

| الملف | الدور |
|---|---|
| `worker/index.js` | الـWorker: الاستضافة، وسيط Yalidine، المزامنة (Durable Object SQLite + مفتاح `KANACH_KEY`)، صندوق وارد FreeVendor، Web Push (VAPID)، فحص كل 15 دقيقة |
| `wrangler.toml` و`.assetsignore` | الإعداد. لا يُنشر علناً إلا ملفات التطبيق |
| `tests/worker.test.js` | اختبارات الـWorker والتطبيق معاً عبر `wrangler dev`، مع Yalidine وخدمة إشعارات محاكيين |

## التشغيل

الطريقة الموصى بها:

```bash
node kanach-proxy.js
```

ثم افتح `http://localhost:8787`. الوسيط يخدم التطبيق ويمرّر طلبات Yalidine من IP حاسوبك، فلا مشاكل CORS ولا حاجة لملء «رابط الوسيط». ومن هذا الرابط يمكن تثبيت كناش كتطبيق، ويعمل بلا إنترنت.

ويمكن أيضاً فتح `kanach.html` مباشرة (لكن بلا تثبيت ولا عمل دون إنترنت).

## الملفات

| الملف | الدور |
|---|---|
| `kanach.html` | التطبيق كاملاً |
| `kanach-proxy.js` | وسيط محلي لـ Yalidine، ويخدم التطبيق، ويستقبل طلبيات FreeVendor (`inbox.json`). اختياري: `KANACH_ORIGINS` لحصر المواقع المسموح لها |
| `sw.js`, `manifest.webmanifest`, `icon.svg` | التثبيت كتطبيق والعمل دون إنترنت |
| `archive/` | النسخ السابقة كما كانت تعمل: قبل الملصقات، وقبل منتجاتي والتسديد (v7)، وقبل كناش السحابي (v8)، وقبل تأكيد الطلبيات (v9)، وقبل الواجهة الجديدة (v10) |
| `CONFIRM.md` | تأكيد الطلبيات بالمكالمة أو واتساب، وإعداد WhatsApp Cloud API |
| `tests/kanach.test.js` | اختبارات في متصفح حقيقي: `node tests/kanach.test.js` (يحتاج Playwright) |

## من FreeVendor إلى Yalidine

FreeVendor لا يوفّر API، فيقرأ كناش صفحة الطلبيات من متصفحك وأنت مسجّل الدخول:

1. شغّل `node kanach-proxy.js` وافتح كناش من `http://localhost:8787`.
2. من **الإعدادات** ← **FreeVendor**، اسحب زر **⇪ كناش ← FreeVendor** إلى شريط المفضلة.
3. في freevendor.space افتح «Gérer les commandes» واضغط الزر. يفتح تفاصيل كل طلبية «Confirmé avec le client» أو «En attente de confirmation» ويقرأها، ثم يرسلها إلى كناش. طريقة الإرسال تختلف حسب الطريقة التي فتحت بها كناش:
   - **من الوسيط المحلي** (`http://localhost:8787`): تصل الطلبيات وحدها. في المرة الأولى يطلب Chrome إذن «الوصول إلى الشبكة المحلية».
   - **من رابط إنترنت** (مثل GitHub Pages): زر «افتح كناش وأرسل».
   - **من ملف على الحاسوب** (`file://`)، أو مع Cloudflare Worker: زر «نسخ إلى كناش»، ثم في كناش زر «لصق من FreeVendor» (في الرئيسية فوق «مسار الطلبيات»، أو في الإعدادات).
4. في كناش تُحسب الفائدة لكل طلبية، وتُطابَق الولاية والبلدية (أو المكتب) مع Yalidine، وتُنشأ الطرود:
   - **Prix du colis = «Prix de vente»** من FreeVendor، وهو يشمل توصيل FreeVendor.
   - **Livraison gratuite مفعّلة**: يدفع الزبون المبلغ نفسه الذي رآه في FreeVendor، ويقتطع Yalidine رسومه منه.
   - في **الرفع التلقائي** (اختياري) يُرسَل فقط ما طابق بثقة كاملة. الباقي ينتظر مراجعتك.

## تأكيد الطلبيات (اتصال / واتساب)

طلبيات FreeVendor **«En attente de confirmation»** تصل إلى طابور **«للتأكيد»**. لا تدخل الأرباح ولا تُرفع حتى يؤكّدها الزبون:

- **بنقرة**: زر اتصال مع نص قصير بالدارجة، وزر واتساب برسالة جاهزة، ثم «أكّد» أو «ألغى» أو «لم يرد».
- **تلقائياً** (WhatsApp Cloud API عبر كناش السحابي): رسالة قالب تُرسل وحدها. ضغط الزبون «نعم» يجعلها «معلّقة» وتُرفع إلى Yalidine، و«لا» تلغيها، وأي ردّ آخر يُعرض عليك.

الإعداد والتكلفة في [CONFIRM.md](CONFIRM.md).

**سعر الشراء:** FreeVendor لا يعرض سعر شرائك. أدخله مرة واحدة لكل منتج (**المنتجات** ← **منتجاتي**)، فتُحسب الفائدة الحقيقية لكل طلبيات ذلك المنتج، السابقة واللاحقة. ما لم تدخله، تُقدَّر الفائدة بالقيمة الافتراضية.

## منتجاتي والتسديد

- **منتجاتي** (**المنتجات** ← **منتجاتي**): المنتجات تُسجَّل وحدها من الطلبيات. سعر البيع يُؤخذ من FreeVendor، وأنت تكتب سعر الشراء فقط في الخانة، فيُحفظ ويُعاد الحساب فوراً. يحسب كناش العمولة (6%) وفائدتك وهامشك وسعر الزبون والصافي بعد التوصيل. عند اختيار المنتج في نموذج الطلبية تمتلئ أسعاره وحدها، وطلبيات FreeVendor تأخذ سعر الشراء منه.
- **التسديد** (**الأرباح** ← **التسديد**): ما عليك تسديده عن الطلبيات المُسلَّمة، أي عمولة 6% من سعر الشراء وفائدة البائع. تختار الطلبيات، وتسجّل التسديد مع ملاحظة، وتنسخ الكشف، ويمكنك التراجع. التسديد لا يغيّر حساب الفائدة، لأن المبلغين محسوبان أصلاً كتكاليف.

## حماية البيانات

- قبل كل تحديث لكناش، وكل أسبوع، تُحفظ نسخة كاملة من بياناتك داخل المتصفح (آخر 6 نسخ). تجدها في الإعدادات ← نسخ احتياطي، وتستطيع استعادتها أو تنزيلها. الاستعادة تحفظ النسخة الحالية أولاً.
- التحديثات لا تحذف ولا تعيد كتابة الطلبيات المسجّلة؛ الحقول الجديدة تُضاف فقط.

## ملصقات الشحن

بعد إنشاء الطرود عند Yalidine يقترح كناش طباعة ملصقاتها. يمكن أيضاً فتحها في أي وقت من الرئيسية ← مسار الطلبيات ← «طباعة الملصقات»، أو من زر «ملصق» في تفاصيل الطلبية.

- كل ملصق يحمل باركود **Code 128** لرقم التتبع (مطابق لمكتبة python-barcode المرجعية)، والزبون، والهاتف، والولاية والبلدية، ونوع التوصيل والمكتب، والمبلغ عند الاستلام، والمنتج، ورقم طلبية FreeVendor، والملاحظة.
- المقاس: 10×15 سم لطابعة حرارية، أو A4 بأربعة ملصقات في الورقة.
- إذا أعاد Yalidine رابط البوردرو الرسمي يُحفظ ويظهر زر «بوردرو Yalidine ↗».

## التحليل

- **المنتجات:** لكل منتج: الطلبيات، نسبة التسليم مقابل نقطة التعادل، الصافي بعد المرتجعات، و**الربح لكل طرد مُرسَل**. ثم قرار (وسِّع / راقب / أوقف أو أعد التسعير)، والسعر أو نسبة التسليم اللازمة لبلوغ هدفك، وتوزيع الطلبيات على الولايات.
- **الولايات:** الطلبيات، والتسليم، والصافي، والمنتج الأكثر طلباً في كل ولاية، ونسبة تركّز طلبياتك في أكبر ثلاث ولايات.
- **المال:** مبالغ التحصيل الموجودة عند Yalidine، والفائدة المتوقعة منها بعد خطر المرتجع، وتوقّع نهاية الشهر، وهدف الشهر مع عدد الطرود اللازمة يومياً.

## الحساب

- سعر التطبيق = سعر المنتج × الكمية + عمولة Vonder (6%) + هامش أمان اختياري (0 افتراضياً، ويبقى لك) + الإضافي + فائدتي
- سعر الزبون = سعر التطبيق + فائدة البائع
- التوصيل: الزبون يدفع سعر توصيل **FreeVendor** فوق سعر الزبون. Yalidine يقتطع سعر توصيله هو، و**0.75%** من المبلغ المحصَّل عند كل تسليم ناجح.
  - تكلفة التوصيل عليك = (Yalidine − FreeVendor) + 0.75% × (سعر الزبون + توصيل FreeVendor)
  - الفائدة الصافية = فائدتي + هامش الأمان − تكلفة التوصيل
  - مثال (أدرار، منزل، سعر زبون 14 600): 1400 − 1000 + 117 = 517 دج عليك، فتصبح فائدة 1048 صافياً 531.
- الجدولان مأخوذان من «Tarifs de livraison» لـ FreeVendor ولـ Yalidine (28/10/2026). FreeVendor لا يوصّل إلى برج باجي مختار وعين قزام وجانت.
- القيمة المتوقعة = نسبة التسليم × الفائدة − نسبة المرتجع × Taxe retour. نسبة التسليم من سجل الولاية إن كانت فيها 5 طلبيات محسومة على الأقل، وإلا النسبة العامة، وإلا القيمة المفترضة.
- يتحقّق التطبيق من النموذج تلقائياً بمقارنته بـ Net الحقيقي للطلبيات المؤكدة.
